# trumpet-tonal-awareness

A trumpet practice method combining technical warm-ups with applied harmony:
chord progressions, inversions, modulation, modal scales, and ear training —
scored as MusicXML and compiled into a practice text.

## Scope

- Core diatonic progressions, circle-of-fifths transposition
- Chord inversions and slash-chord bass lines
- Popular music progressions (1950s–present)
- Modulation and pivot chords
- Modal scales in harmonic context
- Jazz / bossa nova harmony
- Classical brass reference material (original, illustrative — not transcriptions)
- Companion audio: multi-voice harmony awareness, interval harmonization
- Melody writing over fixed progressions and rhythm

## Status

Early development. Structure and content evolving.

## Format

- `/scores` — MusicXML source files
- `/notes` — prose/theory notes accompanying each section
