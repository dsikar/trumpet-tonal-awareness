Chord Progression Analysis, Tonal Awareness & Applied Music Theory for Trumpet
================================================================================

PART 2 — CORE DIATONIC PROGRESSION SET (Key of C major)
--------------------------------------------------------------------------------
Purpose: establish a shared "chord pool" (I, ii, IV, V, vi) used consistently
across later transposition, inversion, and melody exercises.

2.1 Verse:      | C  | Am | F  | G  |   (I - vi - IV - V)
2.2 Chorus:     | F  | C  | G  | Am |   (IV - I - V - vi)
2.3 Middle 8:   | Am | F  | Dm | G  |   (vi - IV - ii - V)

Deliverable: one MusicXML score containing all three 4-bar progressions in
sequence (labeled Verse/Chorus/Middle 8), root-position triads, quarter-note
block chords, C major, 4/4. Roman numerals annotated as lyrics/text below
each chord.

--------------------------------------------------------------------------------
PART 3 — CIRCLE OF FIFTHS TRANSPOSITION
--------------------------------------------------------------------------------
Purpose: technical fluency across all 12 keys; reinforce that chord function
(I-vi-IV-V etc.) is transposition-invariant.

3.1 Transpose the full Verse/Chorus/Middle 8 set (Part 2) clockwise through
    the circle of fifths: C - G - D - A - E - B - F#/Gb - Db - Ab - Eb - Bb - F - C
3.2 Same set, counterclockwise: C - F - Bb - Eb - Ab - Db - Gb/F# - B - E - A - D - G - C
3.3 Note trumpet-specific consideration: written trumpet part will differ from
    concert pitch by a major second (Bb trumpet) — agent should confirm
    transposition is handled correctly in each MusicXML file.

Deliverable: 12 MusicXML files (or one multi-movement file), each containing
the Verse/Chorus/Middle 8 set in a given key, ordered per the circle.

--------------------------------------------------------------------------------
PART 4 — CHORD INVERSIONS
--------------------------------------------------------------------------------
Purpose: train the ear/fingers to recognize chords regardless of bass note;
introduce slash-chord reading and bass-line construction.

4.1 Root position, 1st inversion, 2nd inversion arpeggios for each diatonic
    triad in C major (I, ii, iii, IV, V, vi, vii°)
4.2 Repeat 4.1 for at least one additional key from Part 3 (agent's choice or
    specify — recommend G major and F major as first extensions)
4.3 Slash-chord reading exercise: rewrite Part 2 progressions using inversions
    to create a stepwise/connected bass line (e.g., C - G/B - Am - F)
4.4 (Deferred until Part 7 jazz content is scored) 3rd inversion for 7th chords

Deliverable: MusicXML arpeggio studies (4.1, 4.2) + rewritten progression
score with slash chords and bass-line annotation (4.3).

PART 5 — POPULAR MUSIC PROGRESSIONS (1950s–present)
--------------------------------------------------------------------------------
Purpose: catalogue of ubiquitous pop/rock progressions, named and contextualized.

5.1 Doo-wop changes:        I - vi - IV - V           (C-Am-F-G)
5.2 12-bar blues:           I-IV-V blues form (12 bars, C)
5.3 Andalusian cadence:     i - VII - VI - V           (Am-G-F-E)
5.4 ii-V-I:                 Dm - G - C
5.5 Axis progression:       I - V - vi - IV            (C-G-Am-F)
5.6 vi-IV-I-V variant:      Am-F-C-G

Deliverable: one MusicXML reference sheet with all six progressions labeled
by name/era, root position triads, C major/A minor as shown, 4/4 or 12-bar
form as appropriate.

PART 6 — MODULATION AND PIVOT CHORDS
--------------------------------------------------------------------------------
Purpose: demonstrate modulation technique using pivot chords, common tones,
and direct modulation, across multiple target key relationships.

6.1 Modulation to relative minor (C major -> A minor) — WORKED EXAMPLE ALREADY
    DRAFTED IN CONVERSATION (see below); agent to notate as SATB-style
    4-voice chorale for brass (2 trumpets, horn, trombone OR 2 trumpets +
    trombone, arranger's choice), using progression:
      C(I) - Am(vi/i) - F(IV/VI, pivot) - Dm(ii/iv) - E(V, raised leading
      tone G#) - Am(i)
    Roman numerals shown for both keys at the pivot point (e.g., "IV/VI").
6.2 Modulation to the dominant (C major -> G major), pivot chord technique
6.3 Modulation to the subdominant (C major -> F major), pivot chord technique
6.4 Modulation to parallel minor (C major -> C minor), common-tone technique
6.5 Chromatic mediant modulation example (C major -> E major or Ab major) —
    brief, illustrative only
6.6 Direct/phrase modulation example ("truck driver's" half-step or whole-
    step key change) — brief, illustrative only

Deliverable: MusicXML for 6.1 (full chorale voicing as specified), plus
shorter chord-progression-only MusicXML sketches for 6.2–6.6, each annotated
with Roman numerals in both keys at the pivot point where applicable.

PART 7 — MODAL SCALES IN CONTEXT
--------------------------------------------------------------------------------
Purpose: connect modal scales to real harmonic contexts already established.

7.1 Reference sheet: all seven modes derived from C (Ionian through Locrian),
    one octave ascending/descending, scale notated with mode name labeled
7.2 Mixolydian applied example: progression using a borrowed bVII chord in
    C major (e.g., C - Bb - F - C) to demonstrate rock/blues Mixolydian color
7.3 Dorian applied example: short vamp (e.g., Dm7 - G7 style or static Dm
    vamp) demonstrating Dorian brightness vs. natural minor
7.4 Phrygian applied example: link back to Andalusian cadence (5.3) — brief
    note connecting the two, no new score needed beyond 5.3 if agent judges
    redundant
7.5 Lydian applied example: short illustrative phrase over a IV chord with
    raised 4th, floating/non-resolving character

Deliverable: MusicXML for 7.1 (modes reference sheet), 7.2, 7.3, 7.5.

PART 8 — JAZZ / BOSSA NOVA PROGRESSIONS (EXPANDED)
--------------------------------------------------------------------------------
Purpose: extend harmonic vocabulary to 7th chords, secondary dominants,

8.1 Extended ii-V-I with 7th chords: Dm7 - G7 - Cmaj7
8.2 Turnaround: I - vi - ii - V with 7th chords (Cmaj7 - Am7 - Dm7 - G7)
8.3 Rhythm changes (I Got Rhythm changes) — first 8 bars only, simplified,

8.4 Secondary dominant example: V/V in C major (D7 - G7 - C)
8.5 Bossa-style progression modeled on Jobim harmonic language (illustrative

    Dm7 - G7)
8.6 7th-chord arpeggio reference sheet: dominant 7, major 7, minor 7,
    half-diminished 7 — root position and inversions (root, 1st, 2nd, 3rd)

Deliverable: MusicXML for all of 8.1–8.6.

PART 9 — CLASSICAL / BRASS-RICH REPERTOIRE CONTEXT
--------------------------------------------------------------------------------
Purpose: situate arpeggio-based trumpet technique historically; contrast
Baroque functional clarity with Romantic chromaticism.

IMPORTANT CONSTRAINT: Do NOT transcribe or reproduce copyrighted or
substantial excerpts of actual existing compositions. Where a well-known
work is referenced (e.g., Handel's "The Trumpet Shall Sound," Royal
Fireworks Music), only ORIGINAL illustrative passages "in the style of"
should be composed and notated — clearly labeled as original pastiche, not
as the real piece. Public-domain works (most Baroque/Classical-era pieces)
may be more freely referenced, but agent should still default to original
illustrative writing unless a specific public-domain score is explicitly
sourced and confirmed.

9.1 Original short passage "in the style of" Baroque clarino trumpet writing
    (Handel/Purcell-influenced), diatonic, arpeggio-heavy, natural-trumpet-
    style overtone outlining, brief prose note on historical context
    (valveless trumpet / harmonic series constraint)
9.2 Original short passage "in the style of" Romantic brass writing
    (Brahms/Wagner/Bruckner-influenced), demonstrating chromatic mediant
    modulation and richer harmonic language, contrasted directly against 9.1
9.3 Brief prose notes (no notation needed) on Gabrieli (antiphonal brass)
    and Mahler (exposed Romantic brass writing) as further listening/
    historical references

Deliverable: MusicXML for 9.1 and 9.2 (original compositions only). Prose
notes for 9.3.

PART 10 — INTERVAL & HARMONY AWARENESS (COMPANION AUDIO EXERCISES)
--------------------------------------------------------------------------------
Purpose: ear training / real-time harmonic awareness distinct from arpeggio
drilling — hearing one's own part inside a harmonic texture.

10a. MULTI-VOICE ISOLATED-LINE EXERCISE
10.1 Static/sustained chord version: 2-3 brass voices (2 trumpets + trombone,
     or trumpet/horn/trombone), simple sustained chords built from Part 2
     progression, one voice per part, clearly labeled Voice 1/2/3 with
     Roman numeral + chord-tone role (root/3rd/5th) annotated
10.2 Moving/chorale-style version: same instrumentation, stepwise chorale
     voice leading (model: the Part 6.1 modulation chorale), full 3-voice
     score
10.3 Role-rotation note (prose only): instructions for practicing the same
     chorale with student's part rotated across voice 1/2/3 in successive
     sessions — no new notation needed, reuse 10.2 score

Deliverable: MusicXML for 10.1 (full 3-voice score) and 10.2 (reuse/confirm
6.1 chorale can serve this purpose, or provide a fresh short chorale if
agent judges necessary). Prose for 10.3.

10b. MELODIC HARMONIZATION AT FIXED DIATONIC INTERVALS
10.4 Short original melody (8 bars, C major, stepwise-friendly, moderate
     range) as the reference/backing line
10.5 Harmonization of 10.4 at diatonic 3rds (harmony line above melody)
10.6 Harmonization of 10.4 at diatonic 6ths (harmony line above melody,
     demonstrating interval inversion of 3rds when range requires harmony
     to sit above rather than below)
10.7 Harmonization of 10.4 at diatonic 4ths/5ths (open/parallel harmony,
     brief prose link to historical organum practice)
10.8 Harmonization of 10.4 at octaves

Deliverable: MusicXML for 10.4 (melody alone) plus 10.5–10.8 (each as a
2-voice score: original melody + harmony line, clearly labeled).

--------------------------------------------------------------------------------
PART 11 — MELODY WRITING OVER FIXED PROGRESSION + RHYTHM
--------------------------------------------------------------------------------
Purpose: capstone/appendix exercise — composing melody that fits a given
rhythmic template and remains harmonically coherent with a given progression.

11.1 Define one fixed rhythmic template (agent may propose a simple
     syncopated 4-bar pattern suitable for pop/rock feel) to be reused
     across 11.2–11.4
11.2 Chord-tone-only melody over the Verse progression (Part 2.1) using the
     11.1 rhythm — melody restricted strictly to current chord tones
11.3 Same progression/rhythm, melody now including passing/neighbor tones on
     weak beats, resolving to chord tones on strong beats
11.4 Same progression/rhythm, melody now including leaps and one or two
     chromatic/borrowed color tones (e.g., referencing Mixolydian bVII from
     Part 7.2) for expressive contrast
11.5 Brief prose note on extending this exercise to real-time improvisation
     (no notation needed)

Deliverable: MusicXML for 11.2, 11.3, 11.4 (three versions of melody over
same chords/rhythm, clearly labeled by stage).
